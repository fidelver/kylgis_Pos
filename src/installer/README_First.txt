Project: KylGis POS 1.0
Topic: First installation notes
Maintainer: KylGis POS Project
Date: 8 October 2026

KylGis POS 1.0 requires Java 8. Use a Java build matching the operating system
and CPU architecture. JavaFX is required only when the Kitchen capability is
installed.

Do not copy Java executables into Windows system directories. Configure JAVA_HOME
or PATH normally, or select a valid Java installation in your deployment tooling.

For current setup, multinode provisioning and database guidance, read the main
README and KylGis project documentation.
